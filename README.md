## Play

Download [LeoMiniGames](https://github.com/YoungLionOrganization/LeoMiniGames/releases)
and install games from its in-app store. The table shows the versions in this
repository. For a locally built package, open the RCC in LeoMiniGames.

## Build from source

Install Python 3.11 or newer and the Qt 6 resource compiler, `rcc`. From the repository root,
build a game by its folder name.

```sh
python tools/build_game.py snake_circuit --rcc /path/to/rcc
```

Omit `--rcc` if the compiler is on `PATH`, or set `LMG_RCC` to its path. The
versioned RCC and SHA-256 checksum are written to `games/<game_id>/dist/`.
Successful GitHub Actions runs also provide these files as downloadable artifacts.

Each game's workflow runs when its source or shared build files change and can
be run manually from the Actions tab. CI validates the package and runs the
game-specific regression checks where available.

## Store publishing

Run `python tools/publish_games.py` to compare local and store versions. See [store publishing](docs/store-publishing.md) for the maintainer command.
